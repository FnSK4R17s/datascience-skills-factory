Generate product requirement documents in the Karpathy LLM Wiki style —
abstract enough to not over-specify, concrete enough to be actionable.
Designed to be copy-pasted into an LLM agent's context for implementation.

## Installation

```bash
npx skills add FnSK4R17s/datascience-skills-factory --skill prd-karpathy-style
```
