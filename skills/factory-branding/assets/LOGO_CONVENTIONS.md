# Logo Conventions

## Design System

All repos and skills in this ecosystem use the same logo pattern:
**Microsoft Fluent 3D emoji** rendered as transparent PNG, composited
side-by-side, and displayed at a fixed height in READMEs.

Logos are defined in [`branding.yml`](branding.yml) and generated by
the [factory-branding](https://github.com/FnSK4R17s/datascience-skills-factory/tree/main/skills/factory-branding) skill.

## How to Generate

1. **Define** the emoji in `branding.yml` under `skills:` or `repo:`
2. **Run** the generation script:

```bash
# Single skill
./path/to/factory-branding/scripts/generate-logo.sh \
  --config branding.yml --skill <skill-name>

# All skills missing a logo
./path/to/factory-branding/scripts/generate-logo.sh \
  --config branding.yml --all

# Repo-level logo
./path/to/factory-branding/scripts/generate-logo.sh \
  --config branding.yml --repo
```

3. **Commit** the generated `logo.png`

### Source Assets

- **Font**: [Microsoft Fluent Emoji 3D](https://github.com/microsoft/fluentui-emoji)
- **Method**: Individual emoji PNGs composited side-by-side at equal height via Pillow
- **Background**: Transparent PNG (RGBA)
- **Output**: `logo.png` at skill or repo root

### Display Sizes

| Emoji count | README height | When to use |
|-------------|---------------|-------------|
| 1-2 (base only) | `height="97"` | Core repo, single base mark |
| 2-3 (base + suffix) | `height="88"` | Skills, sub-repos |
| 4+ (repo-level) | `height="97"` | Repo logos with multiple emojis |

## Rules

- **Always include the base mark** — it's the brand anchor
- **One suffix emoji per skill** (two max for repo-level logos)
- **Use Fluent 3D style only** — no Twemoji, no Apple emoji, no flat icons
- **Transparent background** — works on light and dark GitHub themes
- **No text in the logo** — the name goes in the `<h1>` below it
- **No duplicate suffixes** — each skill/sub-repo gets a unique emoji

## Adding a New Entry

1. Pick a suffix emoji that:
   - Represents the skill's function at a glance
   - Is distinct from existing suffixes
   - Exists in the [Fluent 3D emoji set](https://github.com/microsoft/fluentui-emoji/tree/main/assets)
2. Add it to `branding.yml` under `skills:`
3. Add a row to the suffix table above
4. Generate the logo
5. Add the README header
